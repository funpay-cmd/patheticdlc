# Magic Camera — Doctor Strange Edition 🪄

Приложение для вебкамеры с эффектами в стиле **Доктора Стрэнджа**.

## Что умеет

- **Определение позы** — распознаёт человека в кадре и рисует светящийся скелет (33 точки тела)
- **Отслеживание рук** — отслеживает обе руки и все пальцы в реальном времени
- **Магические эффекты при движении пальцев:**
  - искры и частицы, летящие от кончиков пальцев
  - светящиеся следы (trails) за каждым пальцем
  - мистические руны, появляющиеся при быстром движении
  - вращающийся портал (мандала) при раздвинутых пальцах
  - эффект свечения (glow) на всех частицах
- **3 цветовые палитры:** оранжево-золотая, синяя мистическая, зелёная энергия

## Установка

```bash
# Python 3.9+
cd magic-camera
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

| Клавиша     | Действие                           |
|-------------|-------------------------------------|
| `Q` / `ESC` | Выход                              |
| `P`         | Сменить палитру цветов              |
| `M`         | Вкл/выкл зеркальный режим          |
| `S`         | Вкл/выкл отображение скелета       |
| `H`         | Показать/скрыть подсказки           |

## Как работают эффекты

1. **Скелет** — MediaPipe Pose определяет 33 точки на теле; соединения рисуются линиями, суставы — кругами с ореолом.

2. **Искры** — при движении пальцев от их кончиков разлетаются частицы. Чем быстрее движение, тем больше искр.

3. **Следы (Trails)** — каждый палец оставляет светящийся след, который угасает за ~0.6 секунды.

4. **Руны** — при резких движениях с небольшой вероятностью появляются мистические символы.

5. **Портал** — когда пальцы одной руки раздвинуты, вокруг руки появляется вращающийся портал-мандала из двух колец с декоративными элементами (как в фильмах Marvel).

6. **Glow** — все яркие частицы имеют эффект свечения через размытие (Gaussian Blur).

## Требования

- Python 3.9+
- Вебкамера
- Библиотеки: OpenCV, MediaPipe, NumPy (см. `requirements.txt`)
